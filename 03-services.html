3. Services: Die Geschäftslogik auslagern

Alltag: Der Kellner kocht nicht selbst: Er gibt die Bestellung an die Küche. Die Küche weiß, wie man kocht.
Merksatz: Der Controller delegiert, der Service entscheidet und rechnet.

Problem aus Seite 2: Der Controller ist voll mit Rabatt, Datenbank und Mail (Fat Controller).

Idee: Fachliche Abläufe wandern in eigene Klassen, die Services. Der Controller ruft sie nur noch auf.

Vorher / Nachher

Vorher 
Anlegen(Bestellung b)
{
    validieren...
    rabatt rechnen...
    SQL schreiben...
    Mail senden...
    return Ok(ergebnis);
}
Nachher 
Anlegen(Bestellung b)
{
    _service.Anlegen(b);
    return Ok(ergebnis);
}

BestellService

public class BestellService
{
    public void Anlegen(Bestellung b)
    {
        b.Summe = new RabattService().Berechne(b);   // Regel
        new BestellRepository().Speichern(b);         // Speichern
        new MailService().SendeBestaetigung(b);       // Benachrichtigen
    }
}

public class RabattService
{
    public decimal Berechne(Bestellung b)
    {
        var summe = b.Menge * b.Preis;
        return b.Menge > 10 ? summe * 0.9m : summe;
    }
}
Gewonnen:
  • Rabatt-Änderung an genau einer Stelle.
  • API, Konsole und Web können denselben Service nutzen.
  • Der Controller bleibt klein und lesbar.

Was ist ein Service, was nicht?

ServiceKein Service
Fachliche Abläufe und Regeln ("Bestellung anlegen")Alles, was man nicht einordnen kann ("Helper", "Manager", "Utils")
Ein klarer Name, eine klare AufgabeEine Klasse mit 30 Methoden zu 10 Themen
Kennt keine HTTP-Details (Request, Response, Statuscodes)Klassen, die HttpContext, Request oder IActionResult kennen
Vorab: In den Beispielen geben wir noch die Bestellung selbst zurück. Warum das keine gute Idee ist und was man stattdessen schickt, zeigt die nächste Seite.
Neues Problem: Schau dir new RabattService(), new BestellRepository() und new MailService() an. Der BestellService erzeugt seine Helfer selbst.
Wie testest du Anlegen, ohne dass eine echte Mail rausgeht? Wie tauschst du die Datenbank aus? Gar nicht. Das ist der Einstieg in Seite 4.
